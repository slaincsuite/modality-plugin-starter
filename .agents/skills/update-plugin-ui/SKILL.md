name: update-plugin-ui
description: Update the optional Vue console UI or plugin route declarations.
---

1. Inspect `ui/src/index.ts`, `ui/src/views/`, and `plugin/ui/routes.json`.
2. Keep route names, paths, and menu declarations consistent.
3. Use Chinese UI text and avoid host-only components.
4. Run UI checks and `make package` when declaring a new route.
